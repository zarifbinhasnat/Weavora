sequenceDiagram
    participant Student
    participant UI as DocumentsManager
    participant Embed as embeddings.ts
    participant Gemini as Gemini API
    participant FBS as Firebase Storage
    participant FFS as Firestore

    Student->>UI: Uploads PDF
    UI->>FBS: Upload PDF file
    FBS-->>UI: Download URL
    UI->>FFS: Save document metadata
    UI->>Embed: generateEmbeddingsFromLink(file)
    Embed->>Embed: readFileAsArrayBuffer(file)
    Embed->>Gemini: Extract text (gemini-2.0-flash + PDF bytes)
    Gemini-->>Embed: Plain text
    Embed->>Embed: splitIntoChunks(text, 500 words)
    loop Each chunk
        Embed->>Gemini: embedContent (gemini-embedding-001)
        Gemini-->>Embed: 768-dim vector
    end
    Embed->>FBS: Store embeddings JSON
    Embed->>FFS: Update doc status to completed
